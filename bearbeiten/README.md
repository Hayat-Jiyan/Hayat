# Bearbeiten

Diese Dateien sind die Pflege-Dateien fuer regelmaessige Inhalte.

- `menu-data.js`: Speisekarte, Kategorien, Gerichtsnamen und Beschreibungstexte
- `prices.js`: alle Preise
- `news-data.js`: Hinweise, Popups und Reservierungssperren fuer geschlossene Gesellschaften
- `reviews-data.js`: Bewertungen auf der Startseite

Nach Aenderungen die Website einmal im Browser neu laden und kurz pruefen.
